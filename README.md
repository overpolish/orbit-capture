# Screenwide

A focused screen and audio recorder for macOS and Windows. Screenwide records;
editing will live outside the app.

## Development

```sh
pnpm install
pnpm tauri dev
```

Create a production bundle with `pnpm tauri build`.

## Stack

- Tauri 2
- Rust
- React 19
- TypeScript
- Vite 7
